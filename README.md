# 70.3 Сторис

Конструктор сторис к IRONMAN 70.3 Turkey (01.11.2026). Работает прямо в браузере телефона: выбрать формат, загрузить фото, вписать текст, сохранить JPG 1080×1920.

Файлы:
- `index.html` — сам конструктор
- `u2netp.onnx` — модель, которая вырезает атлета, чтобы графика вставала за ним
- `demo-*.jpg` — примеры фото
